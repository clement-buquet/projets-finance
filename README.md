# Finance Projects — Python

Market and portfolio analysis in Python, built step by step as part of a transition from engineering to asset management.

## Goal

Build a documented, reproducible analytical toolkit: from raw market data to risk metrics and portfolio construction.

## Tools

- Python
- pandas, numpy
- yfinance (market data)
- matplotlib, seaborn (charts)
- JupyterLab

## Notebooks

| # | Notebook | Content |
|---|----------|---------|
| 01 | 01-donnees-marche.ipynb | Market data: returns, volatility, drawdown |
| 02 | 02-portefeuille.ipynb | Portfolio: correlation, diversification, Sharpe ratio, beta |
| 03 | 03-smci.ipynb | Stock case study: Super Micro Computer vs Nvidia and the S&P 500 (price data, in progress) |
| 04 | 04-Tracking-PEA.ipynb | Diversifying a world-ETF PEA: ETFs vs defensive European stocks, core-satellite variants, volatility and drawdown |
